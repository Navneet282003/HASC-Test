Section A: Definitions

10 questions × 2 marks = 20 marks

Answer each question in one to three lines.

1.What is a variable? Write one example of declaring a variable in Java.[2 marks]
2.What is a data type? Name any two data types in Java.[2 marks]
3.What is the difference between = and ==?[2 marks]
4.What is a conditional statement? Name any two conditional statements in Java.[2 marks]
5.What is the Scanner class? Write the import statement needed to use it.[2 marks]
6.What is a method? Write one advantage of using methods.[2 marks]
7.What is the difference between a parameter and an argument?[2 marks]
8.What is a loop? Name any two types of loops in Java.[2 marks]
9.What is the difference between a while loop and a do-while loop?[2 marks]
10.What is an array? What is the index of the first element in an array?[2 marks]

Section B: Write the Code

5 questions × 4 marks = 20 marks

Question 1 needs a complete program. In Questions 2, 3 and 5 you may skip the class and main lines and write only the code that goes inside main (keep the import line in Question 2). In Question 4, write the method and the main method.

1.Write a complete Java program that prints your name on one line and your city on the next line.[4 marks]
2.Ask the user to enter their age using Scanner. If the age is 18 or more, print Eligible to vote. Otherwise, print Not eligible to vote.[4 marks]
3.Using a for loop, find the sum of the numbers from 1 to 10 and print it.[4 marks]
4.Write a method named square that takes one int and returns its square. Then call it from main with the value 6 and print the result.[4 marks]
5.Create an int array named marks with the values 60, 70, 80, 90, 100. Use a loop to add all the elements and print the sum.[4 marks]

Section C: Guess the Output

5 questions × 2 marks = 10 marks

Read each program carefully. Write exactly what it prints on the screen. Every program runs without errors.

1.What is the output of this code?[2 marks]
int a = 10;
int b = 3;
System.out.println(a + b);
System.out.println(a / b);
System.out.println(a % b);
Your output
2.What is the output of this code?[2 marks]
int marks = 62;

if (marks >= 75) {
    System.out.println("Grade A");
} else if (marks >= 60) {
    System.out.println("Grade B");
} else {
    System.out.println("Grade C");
}
Your output
3.What is the output of this code?[2 marks]
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    System.out.print(i + " ");
}
Your output
4.What is the output of this code?[2 marks]
static int add(int a, int b) {
    return a + b;
}

public static void main(String[] args) {
    int x = add(4, 6);
    System.out.println("Sum = " + x);
    System.out.println(add(x, 5));
}
Your output
